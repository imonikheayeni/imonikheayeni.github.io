# Ayeni Learning Library

Upload this entire folder to your web host and preserve the `assets` folder. Open `index.html` to preview it.

## Features
- Python and R learning paths
- Personal first-person teaching style
- Exercises and suggested answers
- Browser-based progress tracking
- Light and dark themes
- Mobile navigation
- No framework or build process

Edit lesson content in `assets/courses.js` and styling in `assets/styles.css`.
