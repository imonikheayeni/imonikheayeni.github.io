Start simple

The opening sections cover setup and fundamentals. Advanced material stays further down the page.

Practise, don’t memorise

Retype examples, change values and deliberately make small mistakes. That is where most learning happens.

Use it as a reference

You do not have to finish a guide in one sitting. Search for the topic you need and return when a project gives it context.

Interview ready

Each guide now includes a key-terms and interview refresher section so you can practise explaining concepts, not only writing syntax.

New to data work?

Excel or Python are good general starting points. If your immediate goal is reporting and dashboards, start with Excel and SQL before Power BI and DAX.
